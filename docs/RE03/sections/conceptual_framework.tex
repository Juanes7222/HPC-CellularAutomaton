\subsection{Características de los Nodos de Ejecución}
\label{sec:Características de los Nodos de Ejecución} 

Para este proyecto se usaron para los nodos (Head Node y Compute Node) instancias de AWS EC2 m7i-flex.large, las cuales cuentan con las siguientes características:

\begin{itemize}
   \item Instancia utilizada: AWS EC2 m7i-flex.large
   \item Procesador: Intel Xeon Scalable (Sapphire Rapids, 4ta generación)
   \item Cantidad de vCPUs: 2
   \item Cantidad de núcleos: 1
   \item Cantidad de subprocesos/hilos: 2
   \item Frecuencia del procesador: hasta 3.2 GHz
   \item Memoria RAM: 8 GiB DDR5
   \item Arquitectura: x86\_64 (64 bits)
   \item Almacenamiento: EBS Only
   \item Ancho de banda de red: hasta 12.5 Gbps
   \item Sistema operativo: Linux
\end{itemize}
